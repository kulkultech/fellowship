Welcome to the **KulKul Fellowship**! This is a unique, community-driven, and facilitated learning experience designed to help you build real-world software engineering capabilities.

---

## 💡 About Our Program

The KulKul Fellowship is a **peer-to-peer facilitated learning journey**. It is an intensive program where you'll learn how modern software development works.

*   **Mentorship:** You will learn alongside other fellows, reviewing each other's code and discussing designs. You will be facilitated by our experienced team members (a mentorship path that is highly valuable).
*   **Time Commitment:** This is a dedicated learning program. We expect our fellows to commit at least **3 months** with at least **20 hours per week** of active contribution and learning.
*   **AI-Native Focus:** We embrace AI coding assistants. You will learn to use IDEs and agents as copilots, focusing your effort on software architecture, automated testing, and code quality.

---

## 💼 Fellowship Tracks

We welcome applicants for the following specialized roles:

*   **AI Software Engineering Fellow** (focusing on AI-assisted web applications, Vite, and Supabase architectures)
*   **AI Mobile Engineering Fellow** (focusing on AI-assisted mobile application frameworks: Flutter, iOS, and Android)
*   **AI & ML Research Fellow** (focusing on agent workflows, large language models, and orchestration tools like Conductor)

---

## 🏃‍♂️ The First Step: Social Coding

To join the cohort and match for projects, you must complete the **10-Step Onboarding Challenge**. 

This challenge serves as a showcase of your capabilities and git etiquette. It acts as our practical screening process:
1. **GitHub Setup:** Register and get active in our repositories.
2. **Coding Agents Setup:** Learn to set up coding agents like OpenCode, Claude Code, and Antigravity (focusing on Antigravity due to its generous free tier) and configure them securely.
3. **Sandbox Application:** Build and deploy a simple feature to our *Intern Management System* sandbox.
4. **Wiki PR:** Submit your profile page to our Fellows Directory.

Ready to begin? Head over to the [10-Step Challenge](/challenge/) to start!
