Testing is an essential safeguard in software development. In this step, you will learn to prompt your AI assistant to generate tests for your code changes.

---

## 🎯 Step Objectives
*   Compose a detailed prompt instructing your AI agent to write a unit test.
*   Verify your code additions using automated testing.
*   Execute the testing suite locally.

---

## 🏃‍♂️ Action Guide

Rather than writing tests manually from scratch, we delegate test boilerplate to our AI companions while reviewing their accuracy.

### 1. Prompt Your AI Companion
Provide your modified code and ask your AI assistant to draft a test file (`src/App.test.jsx`). 

Here is a sample prompt template to paste:
```text
Context: I am working in a React + Vite application using Vitest and React Testing Library.
Code to test:
[PASTE YOUR FIXED APP.JSX HERE]

Task: Write a unit test file App.test.jsx that tests:
1. That the component renders without crashing.
2. That clicking a task toggles its completion state (verify state change).
3. That task filtering works when clicking 'All', 'Pending', and 'Completed'.

Please write clean, readable test cases and avoid mocks where possible.
```

### 2. Add the Test Code
Create a new file `src/App.test.jsx` in the sandbox directory and write the test code generated by your AI companion.

### 3. Run the Test Suite
Verify that all tests compile and pass successfully:
```bash
npm run test
```
If any test fails, feed the error back to the AI with this prompt:
```text
The following test case is failing:
[PASTE TEST FAILURE OUTPUT]

Can you explain the cause of the failure and suggest the exact code change to fix it?
```
Ensure that `npm run test` prints a green successful output before moving on!
